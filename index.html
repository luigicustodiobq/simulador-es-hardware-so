Os três mecanismos

Polling (E/S programada): a CPU fica num laço lendo o registrador de status do dispositivo até ele ficar pronto (busy-waiting) e depois copia o byte para a RAM ela mesma. Não há interrupções, mas a CPU não faz mais nada enquanto isso.

Interrupção: enquanto o dispositivo trabalha, a CPU executa o processo útil. Quando o byte fica pronto, o dispositivo sinaliza uma IRQ ao controlador de interrupções, a CPU salva o contexto e executa a rotina de tratamento (ISR), que copia o byte. Há uma interrupção por byte.

DMA (Direct Memory Access): a CPU só programa o controlador DMA (endereço do buffer e quantidade). O DMA leva cada byte do dispositivo para a RAM pelo barramento, sem a CPU, e gera uma única interrupção no fim do bloco.

Cores da linha do tempo

  • Verde: a CPU está livre para o processo útil.
  • Vermelho: a CPU está presa na E/S (busy-waiting ou copiando o byte no Polling).
  • Âmbar: a CPU está tratando interrupção (troca de contexto + ISR) ou configurando o DMA.

Fórmulas usadas

Com N = bytes, L = latência e C = custo de interrupção:

  • Polling: total = N × (L + 1); CPU em E/S = total; interrupções = 0.
  • Interrupção: total = N × (L + C); CPU em E/S = N × C; interrupções = N.
  • DMA: total = 2 + N × L + C; CPU em E/S = 2 + C; interrupções = 1.

Relação com o xv6 (Capítulo 5 do livro: Interrupts and device drivers)

O console do xv6 usa a UART 16550 emulada pelo QEMU. Quando uma tecla chega, a UART gera uma interrupção; devintr() em kernel/trap.c pergunta ao PLIC qual IRQ chegou e chama uartintr() em kernel/uart.c, que lê um caractere por vez do registrador de recepção. É o modo Interrupção deste simulador.

A mesma UART também tem uma saída por polling: uartputc_sync() fica em laço lendo o registrador de status (LSR) até o transmissor ficar livre. O kernel usa isso no printf.

Já o disco VirtIO (kernel/virtio_disk.c) funciona como o modo DMA: o driver monta descritores apontando para o buffer na memória, o dispositivo lê/escreve o bloco inteiro direto na RAM e gera uma interrupção quando termina (virtio_disk_intr()).

Simplificações

Um dispositivo, uma CPU, latências fixas, sem FIFO na UART, sem cache, sem prioridades de IRQ e sem roubo de ciclos da CPU pelo DMA. O objetivo é mostrar a ordem dos eventos e o custo relativo de cada mecanismo.
